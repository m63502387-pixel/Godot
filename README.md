# Метель (Godot 4.3+, GL Compatibility)

Запуск: открой проект и жми F5 — стартует главное меню (menu.tscn).

Управление. ПК: WASD + мышь (тяни по правой половине), E — действие, F — костёр, I — рюкзак, Shift — бег, Esc/P — пауза.
Телефон: стик слева, обзор — правая половина, кнопки справа.

Мультиплеер по LAN: в меню «Мультиплеер по LAN» -> «Создать игру» (хост) или «Найти игру / подключиться».
Порты: 24680 (игра, UDP) и 24681 (поиск игр, UDP). Все в одной Wi-Fi сети. Если игра не находится автоматически — введи IP хоста вручную.
Каждый игрок проходит свою метель, но видит остальных, общие костры и общие найденные доски.

Баланс — константы в начале main.gd.
